# Участие в разработке Trupy

1. Создайте ветку от `main`.
2. Установите зависимости командой `npm install`.
3. Перед отправкой изменений выполните `npm run build`.
4. Проверяйте интерфейс минимум в размерах 1440×900, 960×540 и 390×844.
5. Новые задания, оружие и награды добавляйте в `src/data/content.ts`, не дублируя баланс в сценах.
6. Не добавляйте чужие защищённые ассеты: визуальные материалы Trupy должны оставаться оригинальными.

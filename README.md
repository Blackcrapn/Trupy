# Trupy: Долина Мёртвых

**Trupy** — браузерная пиксельная 2D action RPG с видом сверху в сеттинге тёмного фэнтези. Исследуйте открытую Долину Мёртвых, берите сюжетные клятвы и побочные контракты у NPC, покупайте оружие, сражайтесь с нежитью и повышайте репутацию.

🎮 **[Играть в Trupy](https://blackcrapn.github.io/Trupy/)**

## Версия 4.0

- полноценный магазин оружия за заработанное золото с ценами, требованиями репутации и сравнением урона, скорости и дистанции;
- восемь постоянных слотов быстрого выбора оружия с подсветкой активного предмета;
- переключение оружия клавишами `1–8`, колесом мыши и касанием по мобильной панели;
- восемь отдельных пиксельных моделей оружия, которые отображаются непосредственно в руках героя;
- модель оружия следует за направлением героя и реагирует на движение, атаку, рывок и особую способность;
- оружие получает преимущества против определённых архетипов врагов, а быстрая смена в бою даёт краткий бонус урона;
- девять зданий полностью перерисованы как разные архитектурные типы: дома, трактир, кузница, часовня, хижина, склад и цитадель;
- двери и коллизии домов выровнены, перед каждым входом оставлен свободный проём;
- добавлены интерьеры болотной хижины, склада пристани и караульни цитадели — всего девять доступных помещений;
- расчищены дороги и проходы, добавлены ворота в кладбище, руины и Пепельную цитадель;
- автоматические проверки подтверждают доступность всех девяти районов, зданий и интерьеров;
- сохранены исправленная SVG-карта, рывок, способности, разломы, инвентарь, музыка, 14 заданий, 10 NPC и 12 уровней боевого пропуска;
- сохранения предыдущих версий продолжают работать без сброса прогресса.

## Управление

| Действие | ПК | Мобильное устройство |
|---|---|---|
| Движение | `WASD` или стрелки | Левый виртуальный стик |
| Атака | `Пробел` или ЛКМ | Большая кнопка атаки |
| Выбор оружия | `1–8` или колесо мыши | Панель оружия |
| Рывок | `Shift` | Голубая кнопка со стрелкой |
| Особая способность | `R` | Фиолетовая кнопка со звездой |
| Взаимодействие | `E` | Кнопка `E` |
| Зелье | `F` | Кнопка с сердцем |
| Задания | `Q` | Кнопка в верхнем меню |
| Инвентарь | `I` | Кнопка в верхнем меню |
| Карта | `M` | Кнопка в верхнем меню |
| Боевой пропуск | `B` | Кнопка в верхнем меню |
| Пауза | `Esc` | Системная кнопка меню |

## Запуск локально

Требуется Node.js 20 или новее.

```bash
npm install
npm run dev
```

Production-сборка:

```bash
npm run build
npm run preview
```

Проверка данных и адаптивный smoke-тест:

```bash
npm run test:data
npx playwright install chromium
npm run test:smoke
```

## Технологии

- [Phaser 3](https://phaser.io/) — игровой движок и физика;
- TypeScript — игровая логика;
- Vite — разработка и production-сборка;
- CSS — адаптивный DOM-интерфейс;
- Canvas API — процедурно создаваемая пиксельная графика;
- localStorage — сохранение прогресса без сервера.

## Структура

```text
src/
  data/       Мир, предметы, баланс, задания, оружие и NPC
  game/       Сцены экстерьера и интерьеров, типы и события
  systems/    AudioManager, инвентарь, сохранение, квесты и текстуры
  ui/         Адаптивный DOM-интерфейс игры
```

## Публикация

Production-сборка опубликована из ветки `gh-pages`: **https://blackcrapn.github.io/Trupy/**. Vite настроен на подпуть `/Trupy/`; после изменений выполните `npm run build` и обновите содержимое ветки `gh-pages` файлами из папки `dist`.

## Примечание

Игра является самостоятельным оригинальным проектом. Сходство с GTA относится только к общей структуре свободного исследования, NPC и заданий; материалы, персонажи и визуальные элементы GTA не используются.

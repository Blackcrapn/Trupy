# Trupy: Долина Мёртвых

**Trupy** — браузерная пиксельная 2D action RPG с видом сверху в сеттинге тёмного фэнтези. Исследуйте открытую Долину Мёртвых, берите клятвы и контракты у жителей, кузнечьте и улучшайте оружие, выживайте ночью и в бурю, сражайтесь с нежитью и раскрывайте тайны долины.

🎮 **[Играть в Trupy](https://blackcrapn.github.io/Trupy/)**

Вся графика и весь звук создаются процедурно в момент загрузки — в игре нет ни одного файла картинки или аудио. Поэтому она открывается мгновенно и одинаково работает на телефоне и на компьютере.

## Версия 5.0

### Модельки и лёгкое 3D

- новый движок отрисовки: направленный свет, ambient occlusion, контурная подсветка и дизеринг придают плоскому пиксель-арту настоящий объём;
- герой перерисован: пять вылепленных направлений вместо трёх, отдельные кадры покоя, ходьбы, атаки, рывка и получения урона;
- все 9 врагов, 2 босса, 10 NPC, 8 моделей оружия и 65 предметов окружения перерисованы с объёмом, тенями и анимацией;
- 9 зданий стали псевдотрёхмерными: перспективные стены с освещённой и теневой гранью, объёмные крыши, тень от свеса, светящиеся окна;
- 474 текстуры и 93 анимации генерируются при запуске.

### Звук

- вместо одного осциллятора — ADSR-огибающие, свёрточный реверб, расстроенные голоса и фильтрованный шум;
- адаптивная четырёхслойная музыка для каждого региона, которая реагирует на бой и на схватку с боссом;
- многослойный эмбиент со случайными событиями: вороны на кладбище, капель в шахтах, цепи в цитадели, чайки на пристани;
- удары звучат по материалу — кость, броня, хитин, тень и пепел отличаются на слух.

### Мир и атмосфера

- суточный цикл: ночь темнее, опаснее и щедрее на элитных врагов;
- динамическое освещение — фонари, горны, разломы, костры и окна домов дают настоящий свет;
- погода: дождь, гроза, туман и пепельная буря влияют на видимость, а значит и на то, как далеко вас заметят;
- рельеф, берега реки, отмели, течение, два моста и один тайный брод;
- пять скрытых мест и три тайных прохода для тех, кто исследует, а не бежит по дороге.

### Системы

- крафт и улучшение оружия у кузнеца Руны — шесть видов материалов наконец пригодились;
- бестиарий с постепенным раскрытием и 22 достижения;
- рабочие быстрые слоты предметов и действующая дымовая бомба;
- семь архетипов поведения врагов: стрелки, щитоносцы, стайные охотники, телепортирующиеся, тараны, юркие и неутомимые;
- элитные враги, у боссов — три фазы с телеграфированными атаками, призывом и опасными зонами;
- три новых задания и цепочка постигры — всего 17 заданий;
- ощутимая отдача боя: критические удары от серий, отбрасывание, вспышки света, тряска по силе урона.

### Интерфейс

- панели бестиария, достижений и ремесла;
- полоса здоровья босса с фазами, часы, погода, радиальные откаты способностей;
- карта с рельефом, мостами, найденными тайниками, названиями зданий и меткой цели.

Сохранения прошлых версий продолжают работать: схема мигрирует до версии 3 без потери прогресса.

## Запуск локально

Требуется Node.js 20 или новее.

```bash
npm install
npm run dev
```

Production-сборка:

```bash
npm run build
npm run preview
```

## Проверки

```bash
npm run typecheck      # типы
npm run test:data      # целостность мира, квестов и экономики
npm run test:systems   # крафт, бестиарий, достижения, сохранения
npm run test:runtime   # запуск настоящих сцен Phaser в Node
npm run test:smoke     # браузерный тест (нужен npx playwright install chromium)
npm test               # всё подряд
```

`test:runtime` — это headless-харнесс: он поднимает реальные сцены игры с заглушками DOM, Canvas и WebAudio и проверяет, что все текстуры испеклись, анимации ссылаются на существующие кадры, мир наполнился, а цикл обновления и все девять интерьеров работают без исключений. Такие ошибки не видит ни компилятор, ни проверка данных.

Если окружение не даёт установить `tsx`, есть резервный вариант на чистом Node:

```bash
npm run test:node
```

## Технологии

- [Phaser 3](https://phaser.io/) — движок и физика;
- TypeScript — вся игровая логика, строгий режим;
- Vite — разработка и production-сборка;
- Canvas API — процедурная генерация всей графики;
- Web Audio API — процедурная генерация всей музыки и звуков;
- CSS — адаптивный DOM-интерфейс;
- localStorage — сохранение прогресса без сервера, с запасным вариантом в памяти, если браузер блокирует хранилище.

## Структура

```text
src/
  data/       Мир, предметы, баланс, квесты, оружие, рецепты, бестиарий, достижения
  game/       Сцены, типы и события
  systems/
    render/     Движок шейдинга пиксель-арта и палитра
    sprites/    Фабрики спрайтов: герой, враги, NPC, оружие, предметы, здания
    audio/      Синтез, музыка, эмбиент, звуковые эффекты
    world/      Освещение, суточный цикл, погода
    combat/     Поведение врагов, фазы боссов, дымовая бомба
  ui/         Адаптивный DOM-интерфейс
tests/        Данные, системы, runtime-харнесс и браузерный smoke-тест
```

## Публикация

Production-сборка публикуется из ветки `gh-pages`: **https://blackcrapn.github.io/Trupy/**. Vite настроен на подпуть `/Trupy/`; после изменений выполните `npm run build` и обновите содержимое ветки `gh-pages` файлами из папки `dist`.

## Примечание

Игра является самостоятельным оригинальным проектом. Сходство с GTA относится только к общей структуре свободного исследования, NPC и заданий; материалы, персонажи и визуальные элементы GTA не используются.

# Trupy: Долина Мёртвых

**Trupy** — браузерная пиксельная 2D action RPG с видом сверху в сеттинге тёмного фэнтези. Исследуйте открытую Долину Мёртвых, берите сюжетные клятвы и побочные контракты у NPC, покупайте оружие, сражайтесь с нежитью и повышайте репутацию.

🎮 **[Играть в Trupy](https://blackcrapn.github.io/Trupy/)**

## Что уже есть в игре

- связанная карта с домом героя, деревней Серый Холм, кузницей, кладбищем, лесом и проклятыми руинами;
- короткое интерактивное обучение;
- 5 заданий основной цепочки и 3 побочных контракта;
- 7 NPC с диалогами и собственными ролями;
- ближний бой, арбалет и магическое оружие;
- 5 покупаемых или открываемых видов оружия с требованиями репутации;
- противники с преследованием и атаками, включая финального босса;
- золото, опыт, уровни, зелья, награды и автоматическое сохранение;
- бесплатный боевой пропуск на 8 уровней;
- журнал заданий, арсенал, магазин, карта, HUD и меню паузы;
- управление клавиатурой и мышью, а также сенсорные стики и кнопки;
- адаптивный интерфейс для ПК, планшетов и телефонов.

## Управление

| Действие | ПК | Мобильное устройство |
|---|---|---|
| Движение | `WASD` или стрелки | Левый виртуальный стик |
| Атака | `Пробел` или ЛКМ | Большая кнопка атаки |
| Взаимодействие | `E` | Кнопка `E` |
| Зелье | `F` | Кнопка с сердцем |
| Задания | `Q` | Кнопка в верхнем меню |
| Арсенал | `I` | Кнопка в верхнем меню |
| Карта | `M` | Кнопка в верхнем меню |
| Боевой пропуск | `B` | Кнопка в верхнем меню |
| Пауза | `Esc` | Системная кнопка меню |

## Запуск локально

Требуется Node.js 20 или новее.

```bash
npm install
npm run dev
```

Production-сборка:

```bash
npm run build
npm run preview
```

Проверка данных и адаптивный smoke-тест:

```bash
npm run test:data
npx playwright install chromium
npm run test:smoke
```

## Технологии

- [Phaser 3](https://phaser.io/) — игровой движок и физика;
- TypeScript — игровая логика;
- Vite — разработка и production-сборка;
- CSS — адаптивный DOM-интерфейс;
- Canvas API — процедурно создаваемая пиксельная графика;
- localStorage — сохранение прогресса без сервера.

## Структура

```text
src/
  data/       Баланс, задания, оружие, NPC и награды
  game/       Сцены Phaser, типы и события
  systems/    Сохранение, квесты, звук и генерация текстур
  ui/         DOM-интерфейс игры
```

## Публикация

Production-сборка опубликована из ветки `gh-pages`: **https://blackcrapn.github.io/Trupy/**. Vite настроен на подпуть `/Trupy/`; после изменений выполните `npm run build` и обновите содержимое ветки `gh-pages` файлами из папки `dist`.

## Примечание

Игра является самостоятельным оригинальным проектом. Сходство с GTA относится только к общей структуре свободного исследования, NPC и заданий; материалы, персонажи и визуальные элементы GTA не используются.
